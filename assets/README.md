# Profile assets and evidence

All artwork is original SVG generated by `python scripts/build_assets.py`, using only the Python standard library. No remote images, fonts, embeds, tracking pixels, or stats-card services are needed. Technology glyphs are custom illustrations, not official brand logos.

The README uses GitHub-supported `<picture>`, `<source>`, `<img>`, `<sub>`, and basic alignment attributes, alongside Markdown. Theme-specific headers and statistics have a dark fallback. Icons use a fixed dark surface with readable contrast on either page theme. The header only animates decorative node opacity; `prefers-reduced-motion` disables it, and all text stays visible without animation.

## Offline review

Open [dark preview](preview.html) or [light preview](preview-light.html). Both HTML files embed their artwork and can be viewed offline. These approximate GitHub's layout using a local Markdown renderer; they are not screenshots of a published GitHub profile. The PNG previews were captured with local headless Chrome.

To regenerate HTML, install the optional preview dependency with `python -m pip install Markdown`, then run `python scripts/preview_readme.py`. SVG generation itself needs no dependencies. Preview generation also checks image paths, SVG XML, navigation anchors, and the coursework table. All 17 unique GitHub links in the root README returned HTTP 200 during review on 24 October 2026.

The technology section groups project experience into backend, frontend/mobile, databases/background processing, testing, and development tools. Java and Spring Boot are part of the primary backend stack. React/Expo come from UniHub, Next.js from GenDA, and Android from AidBridge. Redis is grouped with data infrastructure and BullMQ with background processing. Testing tools refer to the EShop coursework, without claiming authorship of the application being tested.

## Updating statistics

`profile-data.json` records a **static snapshot**, not live contribution statistics. The public-repository count was read from the GitHub user API on 24 October 2026. The other values count the three team projects and five homework branches featured in this README; they are not GitHub-wide contribution totals.

To refresh, verify the API and featured links, edit the counts/date in `profile-data.json`, run `python scripts/build_assets.py`, and update the snapshot date and image alt text in the root README. No workflow or network access is needed to regenerate artwork.
